## Project Overview
A website for Greenway Farms, a small family-run farm business selling fresh
vegetables to the local community. This is Part 1
of a three-part project: HTML structure only

## Website Goals and Objectives
- Introduce Greenway Farms and its story to visitors.
- Showcase available products.
- Allow visitors to make product enquiries.
- Provide contact details and locations for both farm sites.

## Key Features and Functionality
- 5 linked HTML pages with a consistent navigation menu.
- Enquiry form for product-related questions.
- Contact page listing two locations with an embedded map and contact form.

## Timeline and Milestones
- Part 1: Project planning, research, and basic HTML structure (this submission).
- Part 2: CSS styling, responsive design (planned).
- Part 3: JavaScript functionality and SEO (planned).
